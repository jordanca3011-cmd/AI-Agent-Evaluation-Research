# BLACKSITE: Containment - AI Agent Evaluation Case Study

## Overview

BLACKSITE: Containment is a long-term Roblox and Blender development project used as a real-world environment for evaluating AI agent performance during complex creative software workflows.

The project involves 3D asset creation, game systems development, AI-assisted scripting, project organisation, and maintaining consistency across a large number of interconnected components.

Unlike simple coding benchmarks, BLACKSITE provides a long-horizon environment where AI assistance must maintain awareness of previous decisions, technical constraints, and project goals over extended development periods.

---

## Research Purpose

This case study evaluates how effectively AI agents can assist with:

- Long-term project planning
- Maintaining project context
- Understanding complex requirements
- Generating and modifying code
- Assisting with 3D content pipelines
- Recovering from errors
- Following established design constraints

## AI Evaluation Areas

### 1. Context Retention

Research question:

Can AI agents maintain awareness of previous decisions and constraints throughout a long-running project?

Measurements:

- Does the agent remember previous requirements?
- Does it avoid repeating completed work?
- Does it preserve established design decisions?

---

### 2. Tool Usage

Research question:

How effectively can AI agents interact with complex development environments?

Evaluation areas:

- Blender automation
- Script generation
- File organisation
- Debugging workflows

---

### 3. Code Generation and Debugging

Research question:

Can AI agents produce reliable code for real-world development tasks?

Measurements:

- Code correctness
- Number of fixes required
- Ability to diagnose errors
- Understanding of existing systems

---

### 4. Human-AI Collaboration

Research question:

What balance of human direction and AI autonomy produces the best results?

Measurements:

- Amount of human intervention required
- Task completion speed
- Quality of final output

## Evaluation Metrics

Each AI-assisted task will be evaluated using:

| Metric | Description |
|---|---|
| Task completion | Was the objective completed? |
| Accuracy | Was the result correct? |
| Reliability | Did the process require corrections? |
| Efficiency | How much time was saved? |
| Context awareness | Did the agent maintain requirements? |
| Human intervention | How much guidance was needed? |
