
# Experiment 001: Context Retention in Long-Term AI-Assisted Development

## Overview

This experiment evaluates how effectively an AI agent maintains awareness of project information, constraints, decisions, and objectives during long-term software development workflows.

The purpose is to measure whether AI agents can reliably assist with complex projects where information accumulates over time and where previous decisions influence future tasks.

---

# Research Question

Can AI agents maintain project context and consistently apply previous requirements during long-term, multi-stage development workflows?

---

# Hypothesis

AI agents can provide useful assistance during complex projects, but performance may decrease as project complexity increases unless sufficient context management systems are provided.

---

# Experiment Setup

## Initial Context Provided

The AI agent is provided with:

- Project overview
- Design requirements
- Technical constraints
- Naming conventions
- Previous decisions
- Current development stage

---

## Tasks

The AI agent will be assigned a sequence of related tasks.

Example:

### Task 1

Understand project requirements.

Evaluation:

- Does the agent correctly identify goals?
- Does it recognise constraints?

---

### Task 2

Complete a development task based on previous information.

Evaluation:

- Does the agent apply previous decisions?
- Does it avoid contradicting requirements?

---

### Task 3

Introduce a new requirement.

Evaluation:

- Can the agent adapt without losing previous context?
- Does it maintain consistency?

---

### Task 4

Review previous work.

Evaluation:

- Can the agent accurately describe completed work?
- Can it identify remaining tasks?

---

# Data Collection

The following data will be recorded:

## Context Accuracy

Measures whether the AI correctly understands stored information.

Recorded:

- Correctly remembered requirements
- Forgotten requirements
- Incorrect assumptions

---

## Decision Consistency

Measures whether the AI maintains previous decisions.

Recorded:

- Number of contradictions
- Number of repeated discussions
- Design conflicts created

---

## Task Performance

Measures whether context retention affects task completion.

Recorded:

- Task success/failure
- Required corrections
- Human intervention

---

## Recovery Ability

Measures whether the AI can recover after losing context.

Recorded:

- Amount of information needed to restore understanding
- Time required to return to correct behaviour

# Expected Results

Expected observations:

- AI agents will perform well on individual tasks with clear context.
- Performance may decrease when projects contain many interconnected requirements.
- Agents may require external memory systems or structured documentation for long-term reliability.
- Maintaining explicit project state may improve consistency.
