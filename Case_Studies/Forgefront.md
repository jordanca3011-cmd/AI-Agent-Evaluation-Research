# Forgefront: Weapons Factory Tycoon - AI Agent Evaluation Case Study

## Overview

Forgefront: Weapons Factory Tycoon is a Roblox game development project used as a real-world environment for evaluating AI agent performance in game systems design, scripting, balancing, and iterative development workflows.

The project focuses on building interconnected gameplay systems including factory production, player progression, combat mechanics, capture objectives, vehicles, and rebirth progression.

Unlike isolated coding tasks, Forgefront requires AI assistance to understand relationships between multiple systems and maintain consistency as the project evolves.

---

## Research Purpose

This case study evaluates how effectively AI agents can assist with:

- Game system design
- Economy balancing
- Gameplay logic development
- Code generation and debugging
- Feature iteration
- Maintaining consistency across interconnected systems

---

## Development Environment

Primary tools:

- Roblox Studio
- Luau scripting
- Blender asset workflows
- AI-assisted development tools

---

## Project Complexity

Forgefront contains multiple interconnected systems:

- Factory production economy
- Player progression systems
- Combat mechanics
- Capture point objectives
- Vehicle systems
- Rebirth progression
- Base management
- Multiplayer balancing

Changes to one system can affect other areas of gameplay, making consistency and reasoning important evaluation factors.

## AI Evaluation Areas

## 1. Game Systems Reasoning

Research question:

Can AI agents understand and assist with complex game mechanics where multiple systems interact?

Evaluation areas:

- Understanding gameplay loops
- Suggesting balanced mechanics
- Identifying system dependencies
- Predicting consequences of changes

---

## 2. Economy and Balancing

Research question:

Can AI agents assist with balancing progression systems in a multiplayer environment?

Measurements:

- Quality of balancing suggestions
- Understanding of player progression
- Ability to adjust rewards and costs
- Consistency with design goals

Example systems evaluated:

- Factory income
- Upgrade costs
- Rebirth rewards
- Combat bonuses

---

## 3. Coding and Debugging

Research question:

How effectively can AI agents create and improve gameplay scripts?

Evaluation areas:

- Luau code generation
- Bug identification
- System integration
- Debugging assistance

Metrics:

- Number of corrections required
- Script reliability
- Understanding of existing code structure

---

## 4. Iterative Development

Research question:

Can AI agents support continuous development over multiple design iterations?

Evaluation areas:
